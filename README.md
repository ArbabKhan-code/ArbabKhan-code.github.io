# Arbab Khan — Portfolio

A static portfolio site hosted with GitHub Pages. The site presents verified professional profile details and work examples shared by Arbab, with links to his public LinkedIn and GitHub profiles.

## Preview locally

Open `index.html` in a browser. The site uses its local stylesheet in `css/profile.css`; Google Fonts are optional and load from Google Fonts when online.

## Content notes

- Role dates, impact metrics, contact details, and other facts not confirmed in the available sources are intentionally omitted.
- Legacy page URLs return visitors to the homepage so old navigation does not display outdated profile information.
