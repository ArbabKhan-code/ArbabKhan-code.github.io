# Arbab Khan — Portfolio

A lightweight, single-page portfolio for Arbab Khan, focused on Java backend engineering. It is hosted with GitHub Pages and built from semantic HTML, CSS, and a small amount of vanilla JavaScript.

## Preview locally

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Site files

- `index.html` contains the page content, navigation, social links, and accessible scroll-reveal behavior.
- `css/profile.css` contains the responsive layout, colors, ambient hero treatment, and reduced-motion styles.
- `images/profile/arbab-khan.jpg` is the single optimized portrait used on the page and in its social preview.

There is no package manager, build step, or runtime dependency. The reveal and hero background effects use browser-native APIs and CSS; content remains visible when motion is reduced or JavaScript is unavailable.

## Content notes

Professional details are limited to information confirmed in the public LinkedIn profile and by Arbab. Role dates, performance metrics, private implementation details, and unconfirmed contact information are omitted. Older page URLs redirect visitors to the current portfolio.
